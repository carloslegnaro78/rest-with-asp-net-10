# RestWithASPNET10

## Documentação da API

A documentação interativa da API está disponível nos seguintes endereços durante a execução local do projeto:

### Scalar
- Interface principal:
  - https://localhost:7196/scalar/
- Documentação da versão v1:
  - https://localhost:7196/scalar/v1

### Swagger
- Interface Swagger UI:
  - https://localhost:7196/swagger-ui/index.html
- Especificação OpenAPI (JSON):
  - https://localhost:7196/swagger/v1/swagger.json

## Acessando a documentação

1. Execute a aplicação.
2. Acesse um dos links acima no navegador.
3. Caso apareça um aviso de certificado HTTPS, aceite a exceção para ambiente local.

## Tecnologias de documentação

- **Scalar**: interface moderna para exploração e testes da API.
- **Swagger/OpenAPI**: padrão amplamente utilizado para documentação e consumo de APIs REST.
